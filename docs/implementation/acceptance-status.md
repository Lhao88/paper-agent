## 首版范围限制

- 默认本机单用户，不具备公网多用户认证能力。
- 无OCR；无文字层或解析失败明确降级。多栏顺序未经验证时只标定向阅读。
- 基础引用结构检查不判断语义支持，界面与导出保留人工核验提示。
- 追加检索只能在批准后的retrieve开放窗口受理；进入精读后需要新run。
- 恢复须确认旧worker进程退出。unknown调用没有自动重发入口，需要核对供应商与账本，避免潜在重复费用。
- 列表有分页，但首版尚未提供全部设计中的复杂文献筛选组合及完整的资料状态筛选面板。
- 预算冲突和全局累计上限会受控停止；目前主要通过API返回明确原因，尚未实现所有冲突的专用交互页。
